# Release_A1 Проект — Справка

## Описание
**БУХЛОЧАТ** — официальный хаб для встреч, событий и общих выездов. Это клиентское JS-приложение с простой авторизацией, календарём событий, счётчиком до выезда, алкометром, отслеживанием дней рождения и админ-панелью для CRUD операций.

- **Развёртывание:** GitHub Pages
- **Дополнительно:** fetch для `data/events.json` и `data/birthdays.json`

### Логика приложения (`js/main.js`)

#### Константы
- `HUB_ANSWER = 'лена'` — ответ на вопрос входа
- `EVENTS_KEY = 'buhlo_events_data'` — ключ localStorage для событий
- `BIRTHDAYS_KEY = 'buhlo_birthdays_data'` — ключ для дней рождения
- `REGISTRATIONS_KEY = 'buhlo_registrations'` — ключ регистраций
- `ENCRYPTED_ADMIN_PASSWORD` — пароль админки (зашифрован)
- `HOLIDAYS` — массив праздников (дата в формате MM-DD)
- `DEFAULT_EVENTS` — события по умолчанию

#### Функции входа
- `checkAuth()` — проверка ответа, скрытие auth-overlay
- `goToAdmin()` — переход в админку

#### Функции даты и времени
- `formatDateDisplay(dateString)` — YYYY-MM-DD → DD.MM.YYYY (для UI)
- `parseDateInput(displayString)` — DD.MM.YYYY → YYYY-MM-DD (парсинг ввода)
- `formatDate(dateString)` — любой формат → DD.MM.YYYY с полным годом (для отображения)
- `getNextAnnualDate(monthDay, from)` — расчёт следующей даты праздника/ДР
- `daysBetween(from, to)` — количество дней между датами

#### Счётчик (таймер) — **ИСПРАВЛЕНО**
- `initPage()` — инициализация при загрузке, загрузка/расчёт сохранённой даты
  - Если 17.07 текущего года уже прошла → ставит дату на 17.07 следующего года
  - Иначе → ставит на 17.07 текущего года
- `updateCustomDate(val)` — обновление целевой даты пользователем
- `startTimer()` — запуск интервала, пересчёт каждую секунду
  - Включены console.log для отладки
  - Обрабатывает ошибки try/catch

#### Загрузка данных
- `loadEvents()` — fetch из `data/events.json`, fallback на localStorage
- `loadBirthdays()` — fetch из `data/birthdays.json`, fallback на localStorage

#### Рендеринг
- `renderUpcomingHighlights()` — отображение блока ближайших событий с событиями, ДР и праздниками
- `renderEvents()` — карточки событий с кнопкой "Записаться"
- `renderBirthdays()` — дни рождения, первые 4 + details для остальных

#### Регистрация на события
- `submitRegistration(eventId)` — добавление участника в событие
- `hasUserRegistered(eventId)` — проверка, записан ли пользователь
- `showRegistrationForm(eventId)` — toggle формы записи

#### Алколь-калькулятор
- `calculateAlcohol()` — расчёт закупки на основе интенсивности и дней

## Важные моменты

1. **Авторизация** — сессионная, только в памяти. При перезагрузке нужно вводить заново.
2. **Хранение данных** — localStorage по умолчанию, данные могут быть перезаписаны при новой загрузке из JSON.
3. **Праздники** — отображаются только за 0–3 дня до даты события.
4. **Дни рождения** — пересчитываются ежегодно, сортируются по ближайшей дате.
5. **Таймер** — обновляется каждую секунду, пересчитывает оставшиеся дни/часы/минуты/секунды. По умолчанию считает до 17.07 (следующего года, если текущий год прошёл).
6. **Формат даты для ввода** — DD.MM.YYYY (пользовательский интерфейс), внутри хранится YYYY-MM-DD.
7. **Отладка** — откроешь DevTools (F12 → Console) и будешь видеть логи таймера.

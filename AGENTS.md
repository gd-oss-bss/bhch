# КРИТИЧЕСКОЕ ПРАВИЛО

**НЕ КОМИТИТЬ И НЕ ПУШИТЬ САМОСТОЯТЕЛЬНО. ТОЛЬКО ВЛАДЕЛЕЦ ПРОЕКТА МОЖЕТ ЭТО СДЕЛАТЬ.**

Запрещено выполнять `git commit`, `git push`, `git merge`, создавать PR и любые другие действия, публикующие изменения, без прямой команды пользователя в текущем сообщении. Изменения оставлять в рабочем каталоге.

**Перед началом каждой новой серии изменений ВСЕГДА спрашивать пользователя: не создать ли feature branch для следующих изменений.** Не начинать правки и не создавать ветку, пока пользователь не ответил.

# БУХЛОЧАТ

Статический хаб для событий, дней рождения, праздников и встреч. Проект использует HTML, CSS и vanilla JavaScript; отдельной сборки или SQL-базы в репозитории нет.

## Данные и хранение

Вместо таблиц базы данных используются три JSON-набора:

| Набор | Файл | Формат записи |
| --- | --- | --- |
| События | `data/events.json` | `id`, `title`, `date` (`YYYY-MM-DD`), `time`, `location`, `description`, `participants`, `maxParticipants`; опционально `recurrence: "yearly"` |
| Дни рождения | `data/birthdays.json` | `{ "birthdays": [{ "date": "YYYY-MM-DD", "name": "..." }] }` |
| Праздники | `data/holidays.json` | `{ "holidays": [{ "date": "MM-DD", "name": "...", "event_type": "general" }] }`; тип также может быть `moto` |

Опубликованные JSON-файлы загружаются браузером. Без настроенного proxy события и регистрации хранятся в `localStorage`, а изменения дней рождения и праздников — в локальных черновиках. Чтобы поделиться такими изменениями, скачайте JSON, обновите файл в `data/` и опубликуйте сайт.

Подключение к внешней базе данных в проекте не настроено. Админка может работать с серверным proxy, если задан `window.BUHLO_API_URL`; поддерживаются маршруты `/events` и `/birthdays`. Proxy и авторизация должны быть настроены на сервере; секреты нельзя помещать в клиентский код.

## Запуск и публикация

Откройте сайт через локальный HTTP-сервер или GitHub Pages. GitHub Actions публикует содержимое репозитория при push в `main`; отдельного шага сборки нет. Главная страница — `index.html`, админка — `pages/admin.html` (также доступна через `admin.html`).

## Структура

- `index.html`, `pages/admin.html` — страницы хаба и админки
- `js/main.js`, `js/admin.js` — логика страниц
- `css/` — стили
- `data/` — JSON-данные событий, дней рождения и праздников
- `gallery/`, `images/` — изображения
- `.PROJECT_NOTES.md` — подробная памятка по проекту
